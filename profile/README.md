## What Is GeneMarker

GeneMarker is a software environment for genetic analysis, with a strong focus on forensic and human identification applications. GeneMarker STR analysis supports the interpretation of short tandem repeat data, which is central to many forensic workflows. The software can process data from both traditional capillary electrophoresis and high-throughput sequencing platforms, giving laboratories flexibility in how they handle samples.

For laboratories moving into next-generation sequencing, GeneMarker HTS software provides a dedicated path for analyzing large read datasets. It includes built-in panels for common amplification systems and supports custom panels as well. The analysis process sorts and trims reads, identifies alleles, and generates reports that can be reviewed and compared. GeneMarker forensic DNA workflows benefit from this structured approach, especially when concordance with existing CE data is important.

Accuracy in GeneMarker allele calling is supported by alignment methods that account for the repeat region and flanking sequence variation. This is relevant when variants or stutter peaks could otherwise complicate interpretation. GeneMarker STR analysis can report iso-alleles and sequence details that are not always visible in length-based methods, providing a richer view of the data. GeneMarker mtDNA analysis adds another layer by supporting mitochondrial sequence alignment, variant detection, and comparison across samples.

The software also includes tools for reviewing results, comparing samples, and managing projects. GeneMarker HTS software outputs reports that can support downstream analysis or database submission where appropriate. For laboratories that need a practical and structured way to handle forensic genetic data, GeneMarker provides a focused set of features rather than a broad general-purpose analytics platform.

In use, GeneMarker STR analysis and GeneMarker forensic DNA tools are intended to support trained analysts. The software helps organize data and surface relevant information, but interpretation remains a professional responsibility. GeneMarker allele calling and GeneMarker mtDNA analysis are designed to make that work more efficient and more consistent.
